# Карта маршрутов

Всего 43 маршрута (без статики). Сокращения: **А** — администратор,
**У** — учитель, **Р** — родитель.

## Авторизация и пользователи

| Метод | Маршрут | Назначение | Доступ |
|-------|---------|------------|--------|
| GET, POST | `/login` | вход в систему | все |
| GET | `/logout` | выход | авторизованные |
| GET | `/users` | список пользователей | А |
| GET, POST | `/users/create` | создание пользователя | А |
| GET, POST | `/users/<id>/edit` | редактирование пользователя | А |
| POST | `/users/<id>/delete` | удаление пользователя | А |

## Коды ответов

| Код | Когда возникает |
|-----|-----------------|
| 200 | успешный GET или POST с возвратом страницы |
| 302 | редирект после входа, выхода или сохранения |
| 400 | POST без корректного CSRF-токена |
| 403 | недостаточно прав (роль или чужой класс) |
| 404 | страница или объект не найдены |
| 413 | файл больше 16 МБ |
| 500 | внутренняя ошибка (собственная страница) |
