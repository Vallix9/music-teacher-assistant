# Пояснительная записка (курсовая работа)

Готовый документ: `Курсовая_работа.docx` (45 страниц) и его PDF-копия
`Курсовая_работа.pdf`. Титульный лист не включён — документ начинается с
содержания. Оформление повторяет требования шаблона: A4, поля 3/1/2/2 см,
Times New Roman 14 pt, интервал 1,5, абзацный отступ 1,5 см, выравнивание по
ширине, нумерация страниц с первой, оглавление — поле Word.

## Структура

| Файл | Содержимое |
|------|------------|
| `content_part1.py` | введение, глава 1, таблицы 1–3 |
| `content_part2.py` | глава 2, заключение, список источников (29), приложения А–В |
| `build_report.py` | сборка `.docx`: стили, колонтитул, таблицы, рисунки, листинги |
| `finalize_report.py` | обновление полей и оглавления, экспорт PDF (Word COM) |
| `diagrams/*.mmd` | исходники схем Mermaid (архитектура, жизненный цикл запроса) |
| `make_er_svg.py` | ER-схема: ручная раскладка SVG → PNG (два фрагмента) |
| `render_diagrams.py` | рендер Mermaid в PNG и расчёт кегля подписей |
| `capture_screens.py` | скриншоты интерфейса (Playwright + Edge) |
| `img/` | 16 скриншотов и 4 схемы |
| `audit_pdf.py`, `verify_layout.py` | проверка PDF: пустые страницы, переполнение, таблицы, подписи, оглавление |
| `render_pdf.py` | рендер страниц PDF в PNG для визуальной проверки |

## Пересборка

```powershell
python docs\report\build_report.py      # .docx из content_part1/2
python docs\report\finalize_report.py   # поля + оглавление + PDF (нужен Word)
python docs\report\audit_pdf.py         # текстовый аудит
python docs\report\verify_layout.py     # таблицы, рисунки, оглавление
```

`build_report.py` использует шаблон `kursovaya_rabota_2.docx` только как источник
стилей и параметров страницы; всё содержимое формируется заново.

## Схемы

Mermaid-схемы рендерятся локально через Edge и `mermaid.js` (без `mmdc`):

```powershell
python docs\report\render_diagrams.py
python docs\report\make_er_svg.py
```

Скрипты печатают натуральный размер схемы и расчётный кегль подписей при
вставке в документ: для читаемости он должен быть не меньше 7–8 pt. ER-модель
поэтому разбита на два фрагмента (ядро и учебные сущности) с ручной раскладкой.
