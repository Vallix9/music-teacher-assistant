# Руководство пользователя

## 1. Запуск и вход

1. Запустите приложение:
   ```bash
   python app.py
   ```
2. Откройте в браузере <http://127.0.0.1:5000>.
3. Введите логин и пароль. Демонстрационные учётные записи:

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `admin123` |
| Учитель музыки | `teacher` | `teacher123` |
| Учитель музыки | `teacher2` | `teacher123` |
| Родитель | `parent` | `parent123` |
| Родитель | `parent2` | `parent123` |

После входа открывается главная страница. В правом верхнем углу — кнопка
переключения светлой/тёмной темы, уведомления и профиль пользователя.

## 2. Главная страница

### Учитель и администратор

«Рабочий стол учителя» показывает:

- количество классов, учеников, средний балл и произведений в репертуаре;
- расписание уроков на сегодня (или ближайшие уроки);
- последние выставленные оценки;
- недавно добавленный репертуар;
- ближайшие мероприятия.

### Родитель

«Личный кабинет родителя» показывает только его детей:

- количество классов и детей, средний балл ребёнка;
- расписание уроков детей;
- последние оценки;
- ближайшие мероприятия.

## 3. Классы и ученики

### Добавить класс

1. Откройте раздел **«Классы»**.
2. Нажмите **«Добавить класс»**.
3. Заполните название (`7В`), параллель (`7`), учебный год и учителя.
4. Нажмите **«Сохранить»**.

### Добавить ученика

1. Откройте **«Классы»** → нужный класс.
2. Нажмите **«Добавить ученика»**.
3. Укажите ФИО, при необходимости выберите родителя, дату рождения и телефон.
4. Сохраните. Ученик появится в списке класса.

### Редактирование и удаление

В строке класса или ученика есть кнопки с карандашом (редактировать)
и корзиной (удалить). Удаление требует подтверждения.

## 4. Расписание

1. Откройте **«Расписание»**.
2. Выберите класс в фильтре или нажмите **«Добавить урок»**.
3. Укажите день недели, номер урока, время начала и окончания, кабинет.
4. Система проверит формат времени `ЧЧ:ММ`.
5. Урок появится в сетке соответствующего дня.

## 5. Репертуар

1. Откройте **«Репертуар»**.
2. Нажмите **«Добавить произведение»**.
3. Заполните название, композитора, жанр, класс, сложность и длительность.
4. Для поиска используйте строку поиска и фильтр по классу.

## 6. Планы-конспекты

1. Откройте **«Конспекты»**.
2. Нажмите **«Создать конспект»**.
3. Заполните тему, цель, задачи, тип урока, оборудование, ход урока,
   домашнее задание и критерии оценивания.
4. Сохраните. Конспект можно открыть, отредактировать или удалить.

## 7. Материалы к уроку

1. Откройте **«Материалы»**.
2. Нажмите **«Добавить материал»**.
3. Укажите название, тип занятия, класс.
4. Прикрепите файл (PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, TXT, JPG/PNG/GIF,
   MP3/WAV/OGG, MIDI) или внешнюю ссылку.
5. Максимальный размер файла — **16 МБ**.
6. Для скачивания нажмите кнопку загрузки в строке материала.

## 8. Журнал

1. Откройте **«Журнал»**.
2. Выберите класс, дату и урок.
3. Отметьте посещаемость: присутствовал, отсутствовал, опоздал,
   пропуск по уважительной причине.
4. При необходимости выставьте оценку и вид работы.
5. Нажмите **«Сохранить»**. Повторное сохранение обновляет запись,
   а не создаёт дубликат.
6. По кнопке в строке ученика открывается его индивидуальная карточка
   со всеми оценками и посещаемостью.

## 9. Отчёты

1. Откройте **«Отчёты»**.
2. Выберите класс и период: весь год, месяц или четверть.
3. Система покажет:
   - средний балл и посещаемость по классу;
   - таблицу по ученикам;
   - распределение оценок.
4. Нажмите **«Экспорт CSV»**, чтобы скачать отчёт для Excel.

## 10. Мероприятия

1. Откройте **«Мероприятия»**.
2. Нажмите **«Добавить мероприятие»**.
3. Укажите название, дату, время, место, класс и статус.
4. В списке можно фильтровать мероприятия по статусу.

## 11. Глобальный поиск

Строка поиска находится в верхней панели. Поиск выполняется по:

- классам и ученикам;
- репертуару;
- материалам;
- планам-конспектам;
- мероприятиям.

Родитель видит только данные, относящиеся к его детям.

## 12. Управление пользователями (администратор)

1. Откройте **«Пользователи»**.
2. Нажмите **«Добавить пользователя»**.
3. Укажите логин, e-mail, ФИО, пароль и роль.
4. Роль определяет доступ: администратор, учитель музыки, родитель.
5. Собственную учётную запись удалить нельзя.

## 13. Смена темы

Кнопка **«солнце / луна»** в верхней панели переключает светлую и тёмную тему.
Выбор сохраняется в браузере и применяется на всех страницах, включая страницу
входа.

## 14. Возможные сообщения

| Сообщение | Причина | Что делать |
|-----------|---------|------------|
| «Неверный логин или пароль» | ошибка ввода | проверьте данные |
| «Доступ запрещён» | нет прав | войдите под другой ролью |
| «Форма устарела» | истёк CSRF-токен | обновите страницу |
| «Файл слишком большой» | файл > 16 МБ | уменьшите файл |
| «Недопустимый тип файла» | запрещённое расширение | используйте допустимый формат |
| «Класс с таким названием уже существует» | дубликат | выберите другое название |
