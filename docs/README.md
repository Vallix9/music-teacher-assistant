# Материалы для пояснительной записки

Готовые материалы Этапа 2: диаграммы, описание базы данных, сценарии
использования, карта маршрутов, руководство пользователя и отчёт о тестировании.
Всё оформлено в Markdown с диаграммами Mermaid — их можно скопировать в `.docx`
или экспортировать в PNG/SVG через <https://mermaid.live>.

| Файл | Содержание |
|------|------------|
| `01-architecture.md` | Архитектура приложения, стек, структура модулей |
| `02-database.md` | ER-диаграмма и описание 11 таблиц |
| `03-use-cases.md` | Роли, use-case-диаграмма, сценарии |
| `04-routes.md` | Полная карта маршрутов с правами доступа |
| `05-user-guide.md` | Руководство пользователя |
| `06-testing.md` | План тестирования и результаты (27 тестов) |
