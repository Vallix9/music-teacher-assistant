# Система-помощник учителя музыки в школе

Веб-приложение для автоматизации работы учителя музыки: ведение классов и учеников,
расписания, репертуара, планов-конспектов уроков, материалов, журнала посещаемости
и оценок, а также построение отчётов.

Курсовая работа.

## Технологии

| Компонент       | Технология                              |
|-----------------|-----------------------------------------|
| Backend         | Python 3.10+ / Flask 3.0                |
| ORM / БД        | SQLAlchemy 2.x / SQLite (MySQL-ready)   |
| Авторизация     | Flask-Login, пароли — Werkzeug (hash)   |
| Шаблоны         | Jinja2                                  |
| Frontend        | Bootstrap 5, Bootstrap Icons (CDN)       |
| Хранилище файлов| Локальная папка `app/static/uploads`     |

## Установка и запуск

```bash
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux / macOS
pip install -r requirements.txt
python app.py
```

Приложение будет доступно по адресу <http://127.0.0.1:5000>.

Для быстрого запуска в Windows можно использовать `run.bat`.

База данных создаётся автоматически в `instance/music_assistant.db`
и заполняется демонстрационными данными при первом запуске.

### Переход на MySQL

```bash
pip install pymysql
```

В `.env`:

```
DATABASE_URL=mysql+pymysql://user:password@localhost:3306/music_assistant
```

Схема моделей не зависит от СУБД — менять код не требуется.

## Функциональные модули

1. **Главная страница** — «рабочий стол учителя»: сводная статистика, расписание
   уроков на сегодня, последние оценки, репертуар и ближайшие мероприятия.
2. **Пользователи** (админ) — создание, редактирование, удаление учётных записей,
   назначение ролей.
3. **Классы и ученики** — справочник классов с привязкой учителя, список учеников
   с привязкой родителя и произвольными заметками.
4. **Расписание уроков** — сетка уроков по дням недели, фильтр по классу,
   автоматическая проверка корректности времени.
5. **Репертуар** — список произведений с композитором, жанром, классом, сложностью
   и длительностью; поиск и фильтрация.
6. **Планы-конспекты уроков** — структурированные конспекты (тема, цель, задачи,
   ход урока, оборудование, домашнее задание, критерии оценивания).
7. **Материалы к уроку** — загрузка файлов (PDF, документы, изображения, аудио, MIDI),
   внешние ссылки, привязка к классу и типу занятия.
8. **Журнал** — посещаемость (присутствовал / отсутствовал / опоздал / пропуск по
   уважительной причине) и оценки по видам работ за конкретный урок;
   индивидуальная карточка ученика.
9. **Отчёты** — посещаемость и средний балл по классу и по ученикам,
   распределение оценок, сводка по всем классам, выгрузка в CSV.
10. **Мероприятия и концерты** — афиша с датой, местом, статусом и описанием.
11. **Глобальный поиск** — единая строка поиска по ученикам, классам, репертуару,
    материалам, конспектам и мероприятиям с учётом прав доступа.

## Оформление интерфейса

Интерфейс выполнен в стиле «тёмный концертный зал» (облегчённая тёмная палитра)
и имеет две темы — тёмную и светлую:

- глубокий тёмный фон с деликатными фиолетовыми и золотыми свечениями и волнами
  эквалайзера;
- эффект glassmorphism — полупрозрачные карточки с размытием фона;
- узкая вертикальная панель навигации с иконками и неоновой подсветкой активного
  пункта;
- верхняя строка глобального поиска и профиль пользователя с круглым аватаром;
- градиентные кнопки (фиолетовый → синий) с мягким свечением;
- переключатель светлой и тёмной темы (кнопка «солнце / луна» в верхней панели);
  выбранная тема запоминается в браузере и применяется на всех страницах;
- шрифт Manrope, адаптивная вёрстка для планшетов и телефонов.

## Безопасность

- Пароли хранятся в виде хешей (Werkzeug `generate_password_hash`), открытые пароли
  в базе не сохраняются.
- Секретный ключ задаётся через переменную окружения `SECRET_KEY`.
- Проверка прав доступа выполняется на уровне маршрутов (`staff_required`,
  `admin_required`), данные фильтруются по роли и принадлежности ученика.
- Загрузка файлов ограничена списком допустимых расширений и максимальным размером
  (16 МБ), имена файлов сохраняются в безопасном виде с уникальным префиксом.
