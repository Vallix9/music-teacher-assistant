# Music Teacher Assistant

Система-помощник учителя музыки в школе

## Стек
- Python + Flask
- SQLite (SQLAlchemy)
- Flask-Login
- Bootstrap 5
- Jinja2

## Установка
```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python app.py
```

## Роли
- Админ
- Учитель
- Родитель
